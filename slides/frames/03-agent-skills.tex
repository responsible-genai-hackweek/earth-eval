% 03-agent-skills. The nine skills this project actually wrote, given the whole
% frame. What a skill IS now lives on 02, beside the workflow chain the skills
% carried guidance into; this slide is only the specific nine.
%
% The names are exactly .claude/skills/*/ on this branch. The grouping is
% editorial and is not in the repo:
%   Science     reanalysis-snowpack-comparison, snow-hydrology-fsca-evaluation,
%               modis-merra-regridding, snow-bias-statistics-and-figures
%   Run         earthdata-streaming-checkpoints, resumable-fetch-run-integrity,
%               derived-quantity-integrity
%   Comms       designing-thematic-figures, building-beamer-decks
%
% building-beamer-decks is the deck's own build written down as a skill: the
% Tectonic gates, the theme seam, the figure and mark conventions, and the rule
% that a green build is not proof a page looks right. It is listed on the slide
% it describes, which is the honest place for it.
%
% TWO COLUMNS, name then gloss. A single column of names left the right-hand
% half of every full-width block empty, and bare directory names say nothing to
% a room that has never seen them. Each gloss is compressed from that skill's
% own `description:` frontmatter — which is the mechanism 02 has just described,
% so the slide demonstrates the thing it lists rather than decorating it.
%
% A GLOSS SAYS WHAT THE SKILL GOVERNS, not when to load it. Lifting a skill's
% trigger clause verbatim reads on a projected slide as a claim about THIS deck:
% designing-thematic-figures is triggered by "a figure for readers who already
% know the field", and as a gloss that said the deck's own audience was expert,
% which a hackweek room is not. Compress what the skill CONTROLS instead.
%
% GLOSSES MUST FIT ONE LINE. Sentence fragments, no terminal full stop, and
% about 45 characters is the ceiling. The name column is fixed at 6.05cm with a
% 0.7em gutter after it: the longest name, snow-bias-statistics-and-figures at
% 32 characters, sets ~5.64cm at \small in the mono face, and at the 5.9cm the
% column was first cut to it touched its own gloss with no gap at all. That
% leaves ~8.2cm for the gloss. One that wraps breaks the row grid and costs a
% line the frame does not have.
%
% p{} rather than l for the first column so the gloss column starts at the SAME
% x in all three blocks. Under l each tabular sizes to its own longest name and
% the three blocks step raggedly against each other.
%
% HEIGHT is the binding constraint: nine rows, three block titles and the
% closing line against a body that gained only the few millimetres the dropped
% frame number used to occupy. \arraystretch and the inter-block \vspace are
% both tuned against the render — re-measure if a tenth skill is added.
