% phase left behind counted under it; then what a SKILL is, which is the
% mechanism that carried the guidance into every one of those phases.
%

%              experiment and are deliberately not counted)
%   src/      26 modules (excluding __init__.py)
%   tests/   329 tests across 14 files
% Re-measure before the talk if the branch has moved.
%
% THE TWO BOXES THAT USED TO SIT HERE — "Fixed Before Any Code" and "Fixed
% Before Any Number" — were dropped at David's direction, so that 03 could be
% given over entirely to the eight project skills. Three title attempts and the
% reasoning that killed the first two are in this file's git history. If the
% pair is ever restored, read that first: the failures were about VOCABULARY,
% not layout, and they build clean and read fluently while saying nothing.
%
% THE SKILL.md CARD came from the left column of 03, and it belongs here rather
% than beside the eight names: a skill is HOW the guidance reached each phase of
% the chain above it, so the two halves of this slide are one mechanism. It is
% DRAWN rather than quoted because the frontmatter is `name` and `description`,
% and the description is what the agent matches on to decide whether to load the
% file at all. That matching is the point, so it gets the annotation.
%
% The card keeps the size it was tuned at in the narrower column. There is spare
% width here, but the extra went to the text beside it, which is the line the
% room has to read from the back — the card is a picture of a file, not
