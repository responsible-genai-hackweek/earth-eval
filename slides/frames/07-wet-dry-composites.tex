% so the aspect ratio \includegraphics sees is the one on the page.
%
% THE DIRECTION IS A TRADE, and it has been made both ways. The month names are
% matplotlib y-labels, already set at 90 degrees in the source, so a rigid
% rotation cannot leave them upright and keep time running forwards:
%   CCW (sips -r -90)  months read November to May LEFT TO RIGHT, but every
%                      month name and Latitude label lands UPSIDE DOWN.
%   CW  (sips -r 90)   labels land upright and readable, but the columns
%                      reverse: May at the left, time running backwards.
% The deck ran CCW until the upside-down labels were caught in a render; it is
% now CW, at David's direction. The caption states the reversed month order
% outright, because the figure no longer reads left to right and a reader who
% assumes it does will read the season backwards.
%
% Only regenerating the figure in a LANDSCAPE layout — months as columns from
% the start — gets upright labels and forward time together. There is no
% generator for this figure on this branch; it survives from the superseded
% fSCA experiment, so that is not a quick change.
%
% After rotation: wet water years on the TOP row, dry on the BOTTOM; within
% each panel latitude now runs horizontally and longitude vertically, which is
% the unavoidable cost of rotating a map figure.
%

% own colorbar says so. They are different spectral-mixture retrievals and

% the other. Slide 08's panels are MODSCAG; do not merge the two captions.
